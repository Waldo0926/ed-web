Ed 整理

把 Ed 论坛和课程内容抓下来，按分类整理，每条给一句话结论。

全程在你自己的浏览器里跑。token 只存在这个标签页里，帖子存在这台电脑的浏览器里， 都不会发给任何服务器。源码公开，可以自己核对。

  • 没有后端页面只请求 edstem.org
  • 关掉标签页即清除token 不落盘
  • 增量刷新只抓有变化的帖子

第一步：让页面能读你的 Ed

Ed 没有对第三方开放的登录授权，所以要把你自己的凭据（token）交给这个页面。两种拿法，任选一种：

方式一浏览器 token

用你现在的登录状态，约 14 天后过期。

  1. 打开任意一个 Ed 页面（edstem.org），确认已登录
  2. 按 ⌥⌘J（Mac）或 Ctrl+Shift+J（Windows）打开控制台
  3. 粘贴这行并回车。Chrome 第一次会拦你，按提示先手打 allow pasting 再粘贴： 
    copy(localStorage.authToken)
  4. token 已经在剪贴板里了，粘到下面的框

方式二API 令牌

在 Ed 的设置页生成，不过期，不用开控制台。能不能在浏览器里用取决于 Ed 的跨域设置，不行页面会提示。

  1. 打开 edstem.org/au/settings/api-tokens
  2. 点 Create token，起个名字，复制生成的令牌
  3. 粘到下面的框。以后不想用了，在同一页删掉就立刻失效
这个 token 等价于你的 Ed 账号完整权限（能替你发帖、删帖、看私密帖）。别把它发给别人，也别贴到你不信任的网站上。
