# Ed Web — 隐私优先的纯前端 Ed Discussion 阅读器

[English](README.md) · **中文**

一个隐私优先、完全在浏览器端运行的 Ed Discussion 课程论坛工具，用于抓取、整理、搜索和总结课程帖子。

线上： https://monashed.secureview.tech/app/

## 隐私模型

这个页面是**纯静态**的，没有应用后端。具体来说：

- 你的 Ed token 只存储在当前浏览器中（`sessionStorage`，关闭标签页后即清除），并且仅会**直接发送给 Ed 官方的 `edstem.org` API**用于身份验证。它不会发送到 `monashed.secureview.tech` 或任何第三方后端。
- 抓取下来的帖子存放在浏览器的 **IndexedDB** 中，不会上传到本站。
- 页面直接从你的浏览器调用 `edstem.org/api/*`。Ed 的 API 返回 `Access-Control-Allow-Origin: *`，因此不需要经过中间代理。

这个仓库保持公开，就是为了让你可以自行核对数据流。全文搜索 `fetch(` 可以看到，请求目标只有 Ed 官方 API 和应用自身的相对路径。

## 怎么用

1. 打开 https://monashed.secureview.tech/app/
2. 按页面提示填写你的 Ed token（页面里提供了两种获取方式）
3. 勾选需要抓取的课程，然后点击「开始抓取」
4. 抓取完成后，可以搜索、按分类浏览，并查看每篇帖子的简短结论

## 总结是怎么做的

不用 LLM，纯规则：

- 有老师/助教回复的帖子 → 取第一条教职工回复的头一两句，并标记「老师答」
- 没有的话 → 取正文第一句
- 关键词标签：截止/延期、时间地点变动、成绩发布、考试安排
- 未解答的提问和 48 小时内的新帖会单独高亮

质量当然不如 AI 生成的摘要，但对于大量只有简短教职工回复的帖子，这已经足够帮助你快速判断是否需要打开原帖。

## 公开展示版与私有 companion

`ed-web` 同时也是我另一个私人学习工作流项目的**公开、隐私安全展示版**。

私人 companion 里还包含一些不适合连同真实课程数据一起公开的工程组件：增量 API 同步、SQLite 持久化、定时任务、静态 dashboard 生成，以及仅手动触发的 AI 整理。这个公开仓库会刻意排除生产凭据、服务器地址、部署路径、原始论坛内容、私密帖子、学生信息、会议密码、签到码、token 和生成数据库。

脱敏后的整体架构与设计取舍见 **[ARCHITECTURE.zh-CN.md](ARCHITECTURE.zh-CN.md)**。

## 相关

抓取逻辑与私人 companion 同源。`ed-web` 保留了核心用户工作流，但把服务端持久化与自动化改成浏览器本地存储和规则式摘要，因此这个公开版本可以独立使用、方便审计，同时不会暴露私人课程数据或生产基础设施。
